# Moofar (PTY) LTD — Company Website

A responsive multi-disciplinary services website for **Moofar (PTY) LTD**, a Botswana-based company.

The project is built with plain HTML, CSS, and JavaScript and does not require a front-end build process.

## Website features

- Responsive page layout for desktop and mobile
- Hero image carousel
- Mobile navigation menu
- Company introduction and team section
- Services grid with eight service categories
- Contact section and enquiry form interface
- Smooth in-page navigation

## Built with

- HTML5
- CSS3
- JavaScript

## Project structure

```
moofar/
├── index.html
├── main.js
├── styles.css
├── assets/
└── .gitignore
```

## Run locally

Open `index.html` in a browser, or serve the project directory with a local development server.

For example, with Python installed:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deployment

The site is a static front-end project. Deploy the website files and retain the asset paths. The repository also includes a Netlify configuration file.

## Contact form

The current project documentation describes the form as a front-end interface that requires an email service or backend integration before it can deliver enquiries.

## Company information

The website contains company contact and location details. Please confirm those details with Moofar before using them for business or procurement purposes.
